# Passenger Counter App

A simple, interactive web application built to track and save passenger counts. This project demonstrates foundational frontend development skills, specifically focusing on JavaScript DOM manipulation and state management.

## Features
* **Increment Counter:** Add to the current passenger count with a single click.
* **Save Entries:** Log the current count and display it in a running history of previous entries.
* **Dynamic Reset:** Automatically resets the active counter to zero after an entry is saved.

## Technologies Used
* HTML5
* CSS3
* Vanilla JavaScript

## Key Learnings
* Selecting and modifying HTML elements using `getElementById()` and `textContent`.
* Writing JavaScript functions to handle mathematical operations and string concatenation.
* Linking JavaScript functions to HTML buttons using `onclick` event listeners.
